# මගේ වියදම් / My Expenses

Simple expense manager built with HTML, CSS and vanilla JavaScript. No backend or database: data is stored in the browser's localStorage on your device.

## Features
- Add income and expenses with category, note and date
- Monthly balance, history and category summary
- Two separate accounts (each with its own data and editable name)
- Logo and favicon (`logo.svg`)
- Dark / Light mode
- Sinhala / English language switch
- Backup (JSON download) and restore

## Run
Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages > Deploy from branch > main / root).

## PWA
The app is installable (manifest + service worker + icons) and works offline. Serve it over HTTPS (GitHub Pages works), then use "Install app" / "Add to Home Screen" in the phone browser.
